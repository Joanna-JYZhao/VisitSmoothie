# 医伴 · 你的私人医生助理

> 说不清的，我帮你说清楚；记不住的，我帮你记住。

医伴帮患者把病情记下来，看病时把整理好的内容直接给医生看。它只做记录、整理和提醒，不做诊断；遇到危险情况直接建议就医。

设计原则只有一条：**对患者越简单越好。一个主屏，说一句话，点一个按钮。** 信息一条不少，只是操作简单。

## 五步流程

| 步骤 | 患者要做的 | 在哪里 |
|---|---|---|
| 1. 建档 | 一屏：称呼、性别、出生年份，再说一句「有什么老毛病、过敏、长期吃的药」，AI 自动分类 | `/onboarding` |
| 2. 记录症状 | 在首页说一句或打一句，或者点一个常见症状。AI 最多连续问 4 个问题，每个都带可以直接点的答案 | `/`，对话在 `/episodes/[id]` |
| 3. AI 定期追问 | 首页的卡片问「今天怎么样了？」，点「好多了 / 差不多 / 更严重了」。新症状每天问一次，拖了两周以上的每周问一次 | `/` |
| 4. 给医生摘要 | 点「给医生看」。第一屏是大字的一眼版，打开就有，可以直接把手机递给医生。细节、打印、复制在下面 | `/doctor/[id]`、`/doctor/year` |
| 5. 存档备用 | 点「看完医生了」，拍照、说一段话或打字。AI 整理成诊断、检查结果、开的药、叮嘱和复查时间，点一下存档。之后继续跟踪，直到点「我好了」。下次再犯，AI 会把这次的记录提出来 | `/after` |

导航只有两个入口：「今天」和「我的档案」。电脑和手机上都是同一个窄列。

「我的档案」（`/me`）里是个人信息、历次记录，以及「更多」：

- **长期管理**开关。有糖尿病、高血压这类要长期记录的情况时打开（建档时提到这类病会主动问一句）。打开后首页按时多问一个数，比如今天的空腹血糖或这周的血压，并用一句话告诉你最近控制得怎么样；「健康指标」页有趋势图，每条记录可以改和删；指标记满两个月或存过两次复诊后，「给医生看」多一个「这一年」页签。
- **设置**：追问节奏、弹出提醒、备份、演示数据、AI 连接测试。

## 少打字

- **说话**：输入框旁边有话筒。点一下开始说，再点一下结束，文字出现在输入框里，确认后发送。
- **拍照**：看完医生后拍病历、处方、药盒或化验单，AI 读出内容并整理。读不准的地方会单独标出来让你确认。
- 照片和录音只用来识别文字，不保存。存下来的只有整理出的文字。

## 快速开始

需要 Node.js 20.9 以上。

```bash
npm install
cp .env.example .env.local   # 填入智谱 GLM 的 API Key
npm run dev
```

打开 http://localhost:3000 。第一次进入是建档，也可以先看演示。

### 两套演示，打开链接就载入

| 链接 | 内容 |
|---|---|
| http://localhost:3000/demo/wang | **王秀兰 · 慢病管理**：58 岁，高血压 5 年，2 型糖尿病确诊后 12 个月的血糖、糖化、体重、血压，换药、副作用、低血糖、假期血糖升高，以及正在跟踪的脚麻。今天是年度复诊日，「长期管理」自动打开 |
| http://localhost:3000/demo/liming | **李明 · 急性症状**：一次还没好的「肚子痛」，加三条以前的记录 |

这台设备上已经有自己建的档案时，链接会先问一句再替换；加 `?replace=1` 跳过询问。演示患者均为虚构。

### 配置（`.env.local`）

| 变量 | 说明 | 默认 |
|---|---|---|
| `GLM_API_KEY` | 智谱开放平台的 API Key。留空时用内置规则引擎回答，语音和拍照不可用 | 空 |
| `GLM_MODEL` | 对话和整理用的模型 | `glm-5` |
| `GLM_VISION_MODEL` | 识别照片用的模型 | `glm-4.6v` |
| `GLM_ASR_MODEL` | 语音转文字用的模型 | `glm-asr-2512` |
| `GLM_BASE_URL` | OpenAI 兼容接口地址。Z.ai 国际版改为 `https://api.z.ai/api/paas/v4` | `https://open.bigmodel.cn/api/paas/v4` |

Key 只在服务端的 `/api` 路由里使用，不会进入浏览器。没有 Key、没有网络或接口报错时，对话、摘要和口述存档自动改用内置规则引擎，演示不会中断；话筒按钮会自动隐藏，拍照会提示改用说或打字。

## 演示脚本

### 李明：一次肚子痛，约两分钟

1. 打开 `/demo/liming`。首页只有一张卡：「肚子痛」今天怎么样了？
2. 点「更严重了」。卡片立刻说「比上次重了，建议今天去看医生」，「给医生看」变成最醒目的按钮，下面出现一个输入框问哪里更严重了。
3. 点「给医生看」。第一屏是给医生的一眼版，按记录生成，马上就有；约 10 秒后下面的细节整理好。点「看全部细节」能看到主诉、现病史、时间线和上次胃炎的记录。
4. 返回首页，点「看完医生了」，点「打字」，输入「医生说是急性胃炎，开了奥美拉唑，每天一次吃两周，让我清淡饮食，两周后复查」，点「整理」，再点「对，存档」。它会问要不要到时候提醒复查。
5. 回到首页，卡片变成「看过医生：急性胃炎」，明天继续问。点「我好了」结束。
6. 在首页输入「胃又痛了」。对话页顶部会提示以前有过类似的情况，AI 的回答也会提到上次。

### 王秀兰：一年的糖尿病管理，约三分钟

1. 打开 `/demo/wang`。首页三张卡，按要紧程度排：今天要去年度复诊；今天的空腹血糖；「脚麻」这周怎么样了。
2. 在血糖那一栏填 `16.5`，点「记下」。它会先问一句「没有填错吧？」。点「填错了，重填」，改填 `6.4`。下面那句话就是最近控制得怎么样，今天记的数旁边有「改」。
3. 点「再记一个数」，填 `3.5`，点「保存」。立刻弹出红色大字：马上吃糖，15 分钟后复测，带一个「拨打 120」按钮。点「知道了」，首页顶部多一张等你填复测值的卡。这些规则不经过 AI。在卡上填 `5.2`，卡片消失。
4. 点复诊卡片上的「给医生看」。第一屏是这一年的一眼版，按记录生成，打开就有，不会中途变；约 25 秒后下面的细节整理好。点「看全部细节」能看到指标变化、两张趋势图、用药调整、重要的事和可以问医生的问题。
5. 回到首页，点复诊卡片上的「看完医生了」，点「拍照」拍一张病历（或点「说给我听」口述）。AI 整理后点「对，存档」。它会问新开的药是不是要长期吃，要不要到时候提醒复查。检查数值自动记进健康指标；话里提到脚麻的话，这次看病也会记到「脚麻」那张卡下面。
6. 进「我的档案」，能看到历次记录、复诊结果，和「更多」里的「长期管理」「健康指标」。

## 技术结构

- **框架**：Next.js 16（App Router）+ React 19 + TypeScript + Tailwind CSS 4
- **数据**：浏览器 localStorage，单用户、无登录。`src/lib/store.tsx` 用 `useSyncExternalStore` 封装
- **AI**：智谱 GLM。对话用 JSON 模式，每轮返回「回复 + 结构化记录 + 快捷回答 + 提示 + 用户报出的数值 + 是否问完了」；照片用视觉模型；语音用语音识别模型

```
src/
  app/
    page.tsx                    今天：输入框，或正在跟踪的症状卡片
    onboarding/                 一屏建档
    episodes/[id]/              对话
    episodes/[id]/detail/       详情：全部记录、变化图、看医生的结果、删除
    doctor/[id]/  doctor/year/  给医生看：这次不舒服、这一年
    after/                      看完医生了：拍照、说话、打字
    me/                         我的档案；me/edit、me/metrics、me/settings
    demo/[persona]/             演示直达链接
    api/chat|summary|annual     对话、单次摘要、年度摘要
    api/after                   整理看病结果（文字或照片）
    api/transcribe              语音转文字
    api/profile                 把一句话拆成病史、过敏、用药
    api/health                  AI 连接状态
  components/                   EpisodeCard、LongTermCard、DoctorSheet、MicButton、SpeakInput 等
  lib/
    checkin.ts                  追问节奏，三个一键答案的处理
    episodeAI.ts                和 AI 的一轮对话（脱离页面运行，换页不中断）
    summaries.ts                给医生的摘要：本地规则先出，AI 版本随后替换
    after.ts                    看病结果的存档
    audio.ts                    录音转 16 kHz 单声道 WAV，长录音在安静处切段
    image.ts                    照片压缩
    metrics.ts                  指标定义、单次读数的告警、规律识别、全年汇总、一句话结论
    ai/prompts.ts               提示词与上下文
    ai/normalize.ts             把模型输出校验成固定结构
    ai/fallback.ts              内置规则引擎：危险信号、读句子、问诊脚本、摘要模板
    demo.ts  demo-wang.ts       两套演示数据
scripts/
```

## 安全边界

- AI 只整理和提醒。不给诊断结论、用药剂量和检查项目，不点名可能的疾病，不猜原因。回复里猜原因的句子会被程序去掉。
- 危险信号由写在代码里的规则判断，不依赖模型，在 AI 回答之前就显示，之后也不会被 AI 的说法替换：胸口痛或闷伴喘不上气、呕血或黑便、神志不清、高烧不退、一侧手脚无力或说话不清、嘴唇喉咙肿等，红色大字建议立即就医或拨打 120，并带一个「拨打 120」按钮。
- 血糖低于 3.9 立即提示吃约 15 克糖并在 15 分钟后复测；血压到 180/110 提示休息 10 分钟后再测。两种情况首页都会留一张等复测值的卡，把提醒跟到底。
- 要不要说「建议今天去看医生」由规则决定：体温到 38.5、说更严重了、说非常难受。AI 可以措辞，不能自己加码。带「今天」的建议过了当天自动消失。
- 不替用户编。「给医生看」的第一屏和时间线完全按记录生成；AI 写的细节会过一遍过滤，用户没说过的「未用药」「无发热」「无手术史」这类话会被去掉；轻重只在用户说了才记；体温按原话记，「38 度多」记 38；没说什么时候开始的，就只写哪天第一次记录。
- 明显离谱的数（比如把 6.5 记成 16.5）存之前先问一句。
- 给医生的页面底部固定注明：患者自己记录、医伴整理，不是诊断。指标的参考范围是一般标准，个人目标以医生为准。

## 当前限制

- 数据只存在这台设备的浏览器里，换设备或清缓存会丢。设置里可以下载备份。
- 弹出提醒只在网页开着时有效。
- 手机通过局域网的 http 地址打开时，浏览器不允许网页用麦克风，话筒会自动隐藏；部署到 https 后才能在手机上用语音。
- 手写病历可能认不准，认不准的地方会标出来。
- `/api` 接口没有鉴权和限流。本机使用没问题，公开部署前需要加上。
- 第一代产品，用于演示和验证思路，不能替代专业医疗意见。

## 双终端协作

本项目用两个 Claude Code 会话协作：主管会话写代码（规则见 `CLAUDE.md`），对接员会话负责和人沟通（规则见 `LIAISON.md`）。在第二个终端运行 `./start-liaison.sh` 启动对接员。进度和每轮模拟用户的结果记在 `PROGRESS.md`，需要人处理的事记在 `HUMAN_TODO.md`，人交来的材料放 `inbox/`，简化方案在 `docs/简化方案.md`。
