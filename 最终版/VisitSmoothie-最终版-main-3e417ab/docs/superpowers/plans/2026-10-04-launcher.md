# Double-click launcher

The user requested an entry program that opens the website when clicked. Implement this in the current main checkout as a macOS `.command` file.

## Design

- `启动 VisitSmoothie.command`: resolve its own directory, find a Node.js 24+ runtime even with Finder's limited PATH, then invoke `scripts/launch.mjs`.
- `scripts/launch.mjs`: install locked dependencies if missing, reuse an existing Next.js listener only when its working directory matches this project, otherwise select an available localhost port and start `next dev`. Wait for `/welcome` to return HTTP 200 before opening the default browser. Keep the owning terminal open and forward stop signals only to the child process group started by this launcher.
- `README.md`: explain double-click startup and how to stop the server. Do not modify application pages, account data, or environment credentials.
