# 医伴简化方案（待确认）

> 目标：对患者越简单越好，核心是「快速把我的信息给医生」。信息一条不少，只是操作变简单。
> 依据：inbox/AI就医助手_项目概述.pdf 的五步，以及两位模拟用户实际试用当前版本后的反馈。
> 状态：**方案，未动工**。确认后再实现。可视化示意：http://localhost:3000/plan.html

## 一句话

**一个主屏，说一句话，点一个按钮。** 首页只回答一个问题：现在该做什么。

## 四条原则

1. 首页同一时间只有一件要做的事。
2. 患者只做两种动作：说一句话（打字或语音），或者点一个大按钮。不填表，不拖滑杆。
3. 信息不减少。趋势图、时间线、历次记录、健康指标、年度摘要都保留，只是从主流程移到「详情」和「更多」里。医生看到的内容不变。
4. 字大、按钮大、说人话。正文 17 号字起，要紧的话 20 号以上，按钮至少 48 像素高，不用小灰字，不出现技术词和需要理解的数字。

## 模拟用户第一轮：两个人，同一个结论

两位模拟用户用当前版本各走了一遍完整流程。他们只能像用户一样用网站，不能看代码。

- **陈浩**，28 岁，只有感冒发烧，图快，表单超过三个框就想关。
- **王秀兰**，58 岁，糖尿病和高血压，老花眼，打字慢，怕点错。

两人被问到「首页只能留三样，你要什么」，答案几乎一样：一个说话的大输入框；正在生的这场病的一张卡；「给医生看」。其余都说收进档案。这正是下面方案的首页。

他们实测的操作量：

| 事情 | 现在要做的 | 谁测的 |
|---|---|---|
| 建档 | 点 7 下，填 2 个框，经过 4 个页面 | 陈浩 |
| 记录喉咙痛和发烧 | 点 13 下，填 2 个框，经过 3 个页面，AI 问到第 4 个问题时烦了 | 陈浩 |
| 第二天更新 | 点 5 下，填 1 个框 | 陈浩 |
| 准备给医生看的 | 点 2 下，等约 25 秒 | 陈浩 |
| 存就医结果 | 点 7 下，表单 6 个框，经过 4 个页面 | 陈浩 |
| 记复诊结果 | 点 11 下，表单 12 个框，打字 5 处 | 王秀兰 |
| 低血糖时求助 | 看到「怎么办」之前要点 5 下、填 2 个框、等约 10 秒 | 王秀兰 |

他们指出的最严重的问题，以及处理方式：

| 问题 | 处理 |
|---|---|
| AI 把同一个问题原样问两遍，刚说发烧又问有没有发烧 | **已修**。原因是模型有时不按格式回答，旧代码把它的回答丢掉改用备用脚本。修后同样的对话重放 18 次，无一次再出现 |
| 烧到 38.5 了，没有一句明确的「该去医院了」，提示还前后矛盾 | **已修**。加重、体温到 38.5、出现新症状时直接说「建议今天去看医生」；旧提示不再残留 |
| AI 说「摘要整理好了」，页面上什么都没有 | **已修**。AI 不再声称做了没做的事，改为指向「给医生看」按钮 |
| 记完就医结果，这场病就被当成结束了，可人还在发烧 | 方案第 5 步：看完医生后继续跟踪，直到你点「我好了」 |
| 低血糖这种急事要先填表才有人理 | 方案第 2 步：首页说一句或填一个数，立刻出大字「马上吃糖」，不用等 AI |
| 复诊回来要填 12 个框，记完别处不跟着变 | 方案第 5 步：说一段话或拍张照，AI 自己分类，并问你要不要更新长期用药和复诊提醒 |
| 字太小，灰字太多 | 原则 4 |
| 「血糖控制得怎么样」没有一句话答案 | 慢病首页用一句大字结论代替四个小卡片 |
| 摘要说是一页，实际两三页；内容重复；「紧急」吓人 | 方案第 4 步：第一屏就是给医生的一眼版，其余折叠；摘要里不再用「紧急」 |
| 摘要里的「疼痛 5/10 升至 7/10」不是用户说的 | 不再替用户打分。有体温、血糖这类数值就写数值 |
| 记错了没处改 | 记完可以撤销，指标可以改和删 |
| 「GLM」「localStorage」「模拟模式」这些词露给患者 | **已从患者界面拿掉**，只留在设置里 |

他们觉得好、要保留的：首页的追问卡片和三个一键答案；对话里的快捷回答；AI 第一句有人味；再次出现同样症状时会提上次；低血糖时第一句就叫吃糖；说出的血糖自动进指标；年度摘要把「目前需要医生关注」放最前；摘要最后那几个替你想好的问题。

## 页面清单：主要页面从 11 个减到 3 个

| 页面 | 做什么 | 对应五步 |
|---|---|---|
| **今天**（首页） | 记录症状、回答追问、去看医生、看完病回来 | 第 2、3、4、5 步 |
| **给医生看** | 第一屏是给医生的一眼版，下面可展开全部细节 | 第 4 步 |
| **我的档案** | 个人信息和历次记录；「更多」里是健康指标和设置 | 第 1、5 步 |

导航只剩两个入口：「今天」和「我的档案」。电脑上也做成和手机一样的窄屏单列，不再有左侧栏和右侧栏。

## 首页长什么样

**没有不舒服时**

```
┌────────────────────────────────┐
│ 医伴                  我的档案 │
│                                │
│  晚上好，陈浩                  │
│  哪里不舒服？告诉我就行        │
│                                │
│ ┌────────────────────────────┐ │
│ │ 说一句或打一句…        话筒 │ │
│ └────────────────────────────┘ │
│  头痛   发烧   咳嗽   肚子痛   │
└────────────────────────────────┘
```

**有正在跟踪的症状时**，首页就是一张卡。这张卡跟着病程变：

```
┌────────────────────────────────┐
│  医伴问你                      │
│  「喉咙痛」今天怎么样了？      │
│ ┌────────┐┌────────┐┌────────┐ │
│ │ 好多了 ││ 差不多 ││更严重了│ │
│ └────────┘└────────┘└────────┘ │
│  想多说两句                    │
│ ┌────────────────────────────┐ │
│ │        给医生看            │ │
│ └────────────────────────────┘ │
│  看完医生了      我好了        │
└────────────────────────────────┘
```

- 点「更严重了」：卡片直接说「比上次重了，建议今天去看医生」，「给医生看」变成最醒目的按钮。
- 点「好多了」：问一句「算好了吗？」，点「好了」就结束。
- 点「看完医生了」：进入第 5 步。存档后同一张卡继续问「退烧了吗？」，并记着医生说的复诊时间。

**慢病患者**（打开了「长期管理」）多两样，都是一行：

```
│  今天的空腹血糖  [      ]  记录 │
│  最近两周空腹血糖平均 6.5，都在 │
│  参考范围内。糖化 6.7%，确诊时  │
│  8.5%。                         │
```

## 五步，每一步怎么走

| 步骤 | 简化后 |
|---|---|
| 1. 建档 | **1 屏**：称呼、性别、出生年份，加一句「有什么老毛病、过敏、长期吃的药？」。可以说话，可以点「都没有」跳过。点 1 次完成，直接进首页 |
| 2. 记录症状 | **首页说或打一句话，点 1 次发送**。时间、轻重、体温由 AI 从话里听出来。AI 最多再问 3 到 4 个问题，每个都带可以直接点的答案。说的话先过一遍本地规则：低血糖、胸痛这类急事立刻出大字提示，不等 AI |
| 3. AI 定期追问 | **点 1 次**：好多了、差不多、更严重了。刚开始每天问；拖了两周以上的慢性症状改成每周问 |
| 4. 给医生摘要 | **首页点 1 次**「给医生看」。第一屏是大字的一眼版：哪里不舒服多久了、最要紧的变化、过敏和病史。直接把手机递给医生。全部细节、打印、复制在下面 |
| 5. 存档备用 | **点「看完医生了」，然后拍照或说一段话，点「存档」**，不用打字。AI 分成诊断、开的药、叮嘱、复查时间，再问你最多两句：「把新药加进长期用药吗？」「到时候提醒你复诊吗？」。之后继续跟踪，直到你点「我好了」 |

轻重不再用 0 到 10 的滑杆。需要问时用三个按钮：有点难受、比较难受、非常难受。系统不替你编分数；有体温、血糖这类实测数值时，记录和摘要里写数值。

## 少打字：语音和拍照

这几项都用你的 GLM Key 实测过。

| 功能 | 能不能做 | 怎么做 | 工作量 | 建议 |
|---|---|---|---|---|
| 说话代替打字，用于描述病情和回答追问 | 能。实测 11 秒的话约 1 秒转成文字，一字不差 | 输入框旁加话筒。点一下开始说，再点一下结束。每段最长 30 秒，超过自动分段 | 小 | 做 |
| 看完病后说一段话，AI 整理存档 | 能，同一套技术 | 「说给我听」，转成文字，AI 整理成诊断、开的药、叮嘱、复查时间，你确认后存档 | 小 | 做 |
| 拍照：病历、处方、药盒、化验单 | 能。实测一张打印病历约 5 秒读出诊断、检查数值、两种药的用法和医嘱，全部正确 | 「拍照」，AI 读出内容，你确认后存档。化验数值自动记入健康指标 | 中 | 做 |
| 手写病历 | 不保证 | 读不清的地方会标出来让你自己确认或补充 | 含在上一项里 | 如实提示 |
| 看病时全程录音 | 技术上能分段转写，但不建议现在做 | 需要征得医生同意，诊室嘈杂，时间长，转写质量没法保证 | 大 | 先不做，用「说一段话」代替 |

两点说明：照片和录音会发给 AI 模型做识别；第一版只保存整理出来的文字，不保存照片和录音原件。两位模拟用户都提到想要语音。
